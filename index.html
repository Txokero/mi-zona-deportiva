Los titulares enlazan a sus medios originales. La aplicación consulta las noticias publicadas en su archivo de datos al abrirse. La actualización del archivo se programa cada hora en GitHub Actions. Los favoritos se guardan únicamente en este navegador.

Esta versión utiliza Google News RSS y GitHub Actions para actualizar el archivo de noticias. La frecuencia real depende de GitHub y de la disponibilidad de las fuentes.
